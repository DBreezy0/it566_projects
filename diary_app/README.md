# Diary Application

This program lets you write diary entries and save them in a text file. Each entry has a date and goes on its own line. You can also look up entries by date.


## How To Run

To start the program, open a terminal in the "diary_app" folder and type "python3 src/main.py"


## What It Does

**Add a diary entry.** Type a date as mm/dd/yyyy or press Return to use today's date.

**Print all entries.** Shows every line in the diary file.

**Print entries for a date.** Shows only the entries written on the date you type.

**Choose the diary file.** Type a file name such as "classnotes.txt" and that file becomes the diary file.

**Load a different diary file.** Switch to a diary file that already exists.

## Where The Entries Are Saved

Diary files are stored in the "data" folder. Each entry is one line like this: "2026-10-06 Text of the entry"
