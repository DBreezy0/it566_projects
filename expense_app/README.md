# Expense Tracker

This program keeps track of what you spend. You can type in an expense, see your expenses on the screen, and save them in a file. You can also open a saved file later, or make a file that opens in Excel.


## How To Run

Open a terminal in the "expense_app" folder. Then type "python3 src/main.py" and press Return.


## What It Does

**Add an expense.** You type the date, the kind of expense, what it was for, and how much it cost.

**Print all expenses.** Shows all of your expenses on the screen.

**Exit.** Closes the program.
