# Expense Tracker

This program lets you enter expenses, filter them, and print them to the console. You can save your expenses in a JSON file, open a saved file later, and export your expenses to a CSV file that opens in Microsoft Excel.


## How To Run

To start the program, open a terminal in the "expense_app" folder and type "python3 src/main.py"


## What It Will Do

**Add an expense.** Type a date, a category, a description, and an amount.

**Print all expenses.** Shows every expense on the console.

**Filter expenses.** Show only the expenses in a date range, in a category, or both.

**Save expenses to a JSON file.** Keeps your expenses so you can use them later.

**Open an expense file.** Loads expenses from a JSON file you saved before.

**Export expenses to a CSV file.** Makes a file you can open in Microsoft Excel.

**Exit.** Closes the program.


## Where The Expenses Are Saved

Expense files are stored in the "data" folder. JSON files end in ".json" and CSV files end in ".csv".
